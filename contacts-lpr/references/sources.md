# Карта источников

Принцип: сначала имя директора (реестры), потом связанные юрлица, потом источники, где компания
**сама** опубликовала прямой контакт (закупки, вакансии), и только в конце — соцсети.

---

## A. Поиск компаний (длинный список)

| Источник | Что даёт | Как искать |
|---|---|---|
| 2GIS, Яндекс.Бизнес, Google Maps | название, телефон, сайт, адрес, отзывы | по рубрике + город; выгружать пачками по районам |
| Rusprofile / Checko / List-Org / Zachestnyibiznes | фильтр по ОКВЭД + регион + выручка + численность | расширенный поиск, сортировка по выручке |
| ЕГРЮЛ (egrul.nalog.ru) | проверка статуса и реквизитов | по названию/ИНН |
| zakupki.gov.ru, B2B-Center, roseltorg, ЭТП ГПБ, ТЭК-Торг | компании, которые **покупают** нужное | поиск по предмету закупки и по ОКПД2, роль — заказчик и поставщик |
| hh.ru, SuperJob, Rabota.ru, Avito Работа, Habr Career | компании, которые растут в нужном направлении | по ключевым словам вакансий + регион |
| Wildberries / Ozon / Яндекс.Маркет | карточка продавца раскрывает ИНН и юр. название | поиск по категории товара |
| Отраслевые ассоциации, реестры лицензий, СРО | закрытые списки участников рынка | сайт ассоциации → раздел «члены» |
| Каталоги выставок и конференций | участники + стенды + ФИО спикеров | PDF каталога участников |
| Рейтинги (Эксперт РА, РБК, отраслевые), премии | крупные игроки сегмента | список номинантов |
| Реестр МСП ФНС, «Прозрачный бизнес» | категория бизнеса, численность, налоговый режим | по ИНН |
| Похожие на эталонных клиентов | «конкуренты компании X» | поиск по фразе + каталоги + рейтинги |

Гигиена длинного списка: сразу фиксируй ИНН — это ключ, по которому потом схлопываются дубли
(одна компания может встретиться как «ООО Ромашка», «Ромашка ТД» и «romashka.ru»).

## B. Глубокий проход по одной компании — 7 шагов

### Шаг 1. Реестры → имя директора за 5 минут
- [ ] `egrul.nalog.ru` — ИНН/ОГРН, юр. адрес, **ФИО гендиректора**, учредители, ОКВЭД, дата регистрации.
- [ ] Rusprofile / Checko / List-Org / Zachestnyibiznes — финансы, численность + **все другие компании этого директора и учредителей**.
- [ ] «Прозрачный бизнес» ФНС — численность, налоговый режим, задолженности, среднесписочная.
- [ ] Реестр МСП — категория бизнеса (микро/малое/среднее).
- [ ] Смена директора за последний год? — если да, старые контакты могут быть мертвы.

**Ключевой ход:** контакты целевой компании закрыты → открой карточки её **связанных юрлиц**.
Телефон и почта там часто в открытом доступе, а владелец тот же.

### Шаг 2. Публикации самой компании (самый ценный слой)
- [ ] `zakupki.gov.ru`, B2B-Center, roseltorg — в документации закупки: **ФИО контактного лица + телефон + почта**.
      Смотри и как заказчика, и как поставщика (в контрактах указан контакт поставщика).
- [ ] `kad.arbitr.ru` — дела, представители, реквизиты; заодно повод для разговора.
- [ ] ЕФРСБ, ФССП — банкротства, исполнительные производства (квалификация и риск).
- [ ] Роспатент — товарные знаки: заявитель, **адрес для переписки** (часто с ФИО и телефоном).
- [ ] Лицензии, сертификаты, декларации соответствия (ФСА) — контактные данные заявителя.

### Шаг 3. HR-источники — самые «болтливые»
- [ ] hh.ru — вакансии: контактное лицо, оргструктура, стек, боли, темпы найма.
      Архивные вакансии тоже читай: контакты в них часто остаются рабочими.
- [ ] SuperJob, Rabota.ru, Habr Career, getmatch, Telegram-каналы вакансий, Авито Работа.
- [ ] Dream Job / «Правда сотрудников» / Otzyvua — в отзывах называют руководителей по именам.

### Шаг 4. Сайт — не только страница «Контакты»

**Если компания пришла из реестра (по ОКВЭД) и сайта в карточке нет — искать сайт обязательно.**
Простейший запрос закрывает большинство случаев: `"<название компании>" <город> сайт`
(прогнать и в Яндексе, и в Google). Пустое поле «сайт» допустимо только после этой попытки.

**Проверка принадлежности сайта.** Найденный сайт должен подтверждаться реквизитами:
ИНН, название юрлица или совпадающий адрес где-то на страницах (низ страницы, «О компании»,
«Реквизиты», оферта, политика обработки данных).

- Реквизиты нашлись и совпали → сайт подтверждён.
- Реквизитов на сайте нет → **не выбрасывать сайт**. Посмотреть, что компания на нём предлагает,
  и сверить с профилем из реестра и с нашим запросом. Если предложение сходится — записать сайт
  с пометкой: **«принадлежность не подтверждена — на сайте нет данных о юрлице»**.
- Сайт явно чужой (другой профиль, другой город, другое юрлицо) → не записывать вовсе
  и указать в комментарии, что найденный по названию сайт принадлежит другой компании.

Телефон и почта, взятые с сайта, наследуют его статус: с подтверждённого сайта — `вероятен`,
с неподтверждённого — `вероятен` с той же пометкой.

**Найденный сайт дочитывать до конца.** Раздел «Контакты», подвал, «О компании», карточки филиалов —
номер часто есть на самом сайте, который уже найден. Указать сайт и не выписать с него телефон — ошибка.

- [ ] `site:domain.ru "@domain.ru"` — вытащить все почты в индексе.
- [ ] `filetype:pdf site:domain.ru` — презентации и КП с ФИО и телефонами.
- [ ] Метаданные найденных PDF/DOCX (`exiftool`, свойства файла) — автор = реальный сотрудник.
- [ ] `web.archive.org` — старые версии, где контакты ещё не прятали.
- [ ] `crt.sh` — поддомены (lk, crm, mail, portal).
- [ ] BuiltWith / SpyOnWeb / DNSlytics — по ID Метрики или GA найти **другие сайты того же владельца**.
- [ ] whois + история whois, reverse IP.
- [ ] Разделы «О компании», «Команда», «Пресс-центр», «Вакансии», «Реквизиты», «Оферта» (там ФИО подписанта).

### Шаг 5. Каталоги и площадки
- [ ] 2GIS, Яндекс.Бизнес, Google Business — телефоны, часы, **ответы владельца на отзывы** (часто с именем).
- [ ] Авито / Юла — магазин компании и объявления сотрудников (в объявлениях личные номера менеджеров).
- [ ] Wildberries / Ozon — карточка продавца раскрывает ИНН и юр. название (работает в обе стороны).
- [ ] Zoon, Flamp, Yell, Профи.ру, отраслевые каталоги.

### Шаг 6. Соцсети и медиа — выход на личность ЛПР
- [ ] VK (владелец сообщества, обсуждения), Telegram (канал + админ), TenChat, Дзен, YouTube/RuTube.
- [ ] Taplink / Linktree в шапке профиля — там пачка контактов.
- [ ] Поиск: `"Название компании" + генеральный директор / основатель / коммерческий директор`.
- [ ] vc.ru, Habr, RB.ru, отраслевые СМИ — интервью с ФИО ЛПР и ссылками на его соцсети.
- [ ] Программы конференций и каталоги выставок — PDF со списком спикеров (ФИО + должность).
- [ ] Рейтинги, премии, пресс-релизы.
- [ ] GitHub — для tech-компаний корпоративные почты в коммитах.

### Шаг 7. Достроить контакт
- [ ] Определи **паттерн корпоративной почты** по 2–3 известным адресам (`i.ivanov@`, `ivanov@`, `ivan.ivanov@`)
      и выведи вероятный адрес ЛПР. Помечай `confidence: гипотеза`.
- [ ] Hunter.io / Snov.io / Apollo (запад), Контур.Компас / Спарк-Лидер (РФ) — если доступны.
- [ ] Обратный поиск найденного номера в Яндексе/Google — связанные объявления и сайты.
- [ ] Проверь, привязан ли номер к Telegram/WhatsApp (есть ли профиль, имя в профиле).
- [ ] Сверь: один и тот же человек мог найтись под разными написаниями ФИО — схлопни.

## C. Поисковые операторы — шпаргалка

```
site:domain.ru "@domain.ru"                     почты в индексе
site:domain.ru filetype:pdf                     презентации и КП
site:domain.ru (директор OR руководитель)       страницы с руководством
"ООО Ромашка" "генеральный директор"            имя ЛПР
"ООО Ромашка" ИНН                               реквизиты в чужих документах
"+7 495 123-45-67"                              обратный поиск номера
"ivanov@domain.ru"                              где ещё светилась почта
site:hh.ru "Ромашка"                            вакансии компании
site:vk.com "Ромашка" директор
site:t.me "Ромашка"
intitle:"контакты" site:domain.ru
"Ромашка" (интервью OR "рассказал" OR "основатель")
```

Полезно: тот же запрос прогнать и в Яндексе, и в Google — индексы заметно расходятся на русских сайтах.

## Граница (обязательно соблюдать)

Всё перечисленное выше — то, что компания опубликовала сама или что публично по закону.

**Не используем:** слитые базы, сервисы «пробива», агрегаторы чужих личных контактов,
домашние адреса, паспортные данные, личные данные вне бизнес-контекста (152-ФЗ).

Для холодного касания рекламного характера формально нужно согласие (38-ФЗ) —
персональное деловое письмо конкретному ЛПР безопаснее массовой рассылки.
Если пользователь просит выйти за эту границу — скажи прямо, что скилл этого не делает,
и предложи легальную альтернативу.
