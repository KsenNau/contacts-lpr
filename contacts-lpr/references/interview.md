# Банк вопросов брифа

Правило: вопросы задаются **блоками**, каждый — нумерованным списком с вариантами, чтобы пользователь
ответил одной строкой. Не вываливай все 30 вопросов сразу: блок 1 и 2 обязательны, блок 3 — по релевантности,
блок 4 — второй круг после анализа ответов.

---

## Блок 1. Цель и портрет (обязательный)

1. **Что продаём / зачем база?**
   Варианты: а) холодный обзвон, б) email-рассылка, в) личные письма ЛПР, г) партнёрство,
   д) найм/переманивание, е) конкурентный анализ, ж) другое.
   *Влияет на то, кто ЛПР и какие поля обязательны.*

2. **Кого ищем — опиши компанию словами.** Что она делает, что покупает, по какому признаку понятно, что «наша».

3. **Отрасль / ОКВЭД.** Если пользователь не знает ОКВЭД — предложи 3–5 подходящих кодов и попроси выбрать.

4. **Есть ли примеры «эталонных» клиентов?** 2–3 названия существующих клиентов — самый быстрый способ
   собрать точный ICP (по ним же ищутся похожие).

## Блок 2. Отсечки (обязательный)

5. **География:** город / регион / список регионов / вся РФ / СНГ. Юридический адрес или фактическое присутствие?
6. **Размер:** выручка (от–до), численность (от–до), отраслевой натуральный показатель (парк техники, число точек, число ТС, площадь склада).
7. **Возраст компании / статус:** только действующие? исключать ли в стадии ликвидации, банкротства, с долгами?
8. **Стоп-лист:** текущие клиенты, конкуренты, компании, с которыми уже общались. Есть ли файл со списком?
9. **Объём:** сколько компаний нужно — 10 / 50 / 200 / «сколько найдётся»?
   *20 компаний с полным досье ≠ 200 с телефоном — уточни приоритет: глубина или ширина.*

## Блок 3. Контакты и триггеры (по релевантности)

10. **Кто ЛПР по этой продаже?** Попроси список должностей по приоритету
    (например: 1 — коммерческий директор, 2 — директор по закупкам, 3 — генеральный, 4 — главный инженер).
11. **Обязательный минимум контакта:** достаточно телефона компании? нужен email? нужен персональный мобильный/Telegram?
    *Компании без нужного минимума — выбрасывать или оставлять с пометкой?*
12. **Триггеры-квалификаторы:** искать ли компании с признаками — активные тендеры, открытые вакансии,
    новые филиалы, судебные дела, новости о расширении, участие в выставках?
13. **Канал первого касания:** звонок / email / Telegram / письмо через сайт / соцсети.
14. **Нужен ли черновик первого сообщения** под каждую компанию (4 строки, с персональным поводом)?
15. **Нужны ли данные для квалификации** помимо контактов: выручка, динамика, налоговый режим, долги, тендерная активность?

## Блок 4. Формат и процесс (обязательный)

16. **Формат выдачи:** а) Markdown-таблица в чат, б) файл в Vault, в) CSV, г) XLSX,
    д) Google Sheets, е) импорт в Битрикс24 (лиды/компании), ж) несколько сразу.
17. **Если Битрикс24:** какой портал, какая воронка/стадия, кто ответственный, лиды или компании+контакты?
18. **Куда сохранить файл:** папка Vault (`40_Projects/<проект>/`), Google Drive, локально?
19. **Дедлайн / срочность:** нужен быстрый черновой список сегодня или полное досье?
20. **Как отчитываться по ходу:** после каждой компании / после каждых 10 / только финал?

## Второй круг: уточняющие после анализа

После первых ответов найди противоречия и пробелы и задай **не больше 3–5** вопросов. Типовые триггеры для уточнения:

- Отрасль описана широко («строительство») → предложи 3–4 подсегмента на выбор.
- Гео «вся Россия» + объём 200 → уточни приоритет регионов, иначе список будет случайным.
- ЛПР назван как «руководитель» → уточни, кто подписывает бюджет по этому вопросу.
- Размер не задан → предложи диапазон по логике продукта («обычно такое покупают компании от 50 человек — берём такую отсечку?»).
- Требуется email ЛПР, но в нише почты закрыты → предупреди заранее: будет много `гипотеза`-почт по паттерну, ок ли это.
- Просят «побольше», но есть жёсткий дедлайн → предложи двухэтапно: сначала широкий список с базовыми контактами, потом углубление по топ-N.

## Итог фазы 0

Собери карточку ICP (шаблон в SKILL.md), покажи её и план источников, дождись подтверждения.
Если пользователь говорит «делай как знаешь» — всё равно зафиксируй письменно принятые допущения,
чтобы потом было видно, по каким критериям собиралась база.
