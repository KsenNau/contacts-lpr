# contacts-lpr — скилл для Claude: сбор базы контактов и ЛПР

Скилл для Claude Code, который собирает **проверяемую базу компаний и лиц, принимающих решения**,
по открытым источникам — под любую нишу.

Не «накидать ссылок», а: снять бриф → найти компании → углубиться по каждой → собрать все контакты
с ролями и источниками → отранжировать так, чтобы первая строка была лучшим входом на ЛПР.

## Что он делает

1. **Бриф.** Задаёт вопросы блоками (кого ищем, гео, размер, кто ЛПР, объём, формат выдачи),
   анализирует ответы, задаёт второй круг уточняющих, показывает карточку ICP на подтверждение.
2. **Длинный список компаний.** Пять заходов: по рубрике (каталоги/карты), по коду (реестры ОКВЭД),
   по деньгам (госзакупки и B2B), по росту (вакансии), по соседям (конкуренты эталонных клиентов,
   клиенты и поставщики целевых компаний). Дедупликация по ИНН, отбраковка, подтверждение списка.
3. **Глубокий проход по компании — 7 шагов.** Реестры (ФИО директора и связанные юрлица) → публикации
   самой компании (закупки, арбитраж, Роспатент) → HR (вакансии, отзывы сотрудников) → сайт
   (`site:`, `filetype:pdf`, метаданные документов, Wayback, поддомены, ID аналитики) → каталоги и площадки →
   соцсети и медиа → достройка контакта (паттерн корпоративной почты, обратный поиск номера).
4. **Ранжирование.** Ступени 1–6 по качеству найденного входа на ЛПР, тир A/B/C. Без выдуманных баллов:
   ступень описывает то, что физически найдено, поэтому одинаково работает в любой отрасли.
5. **Выдача.** Markdown, CSV, XLSX (скрипт в комплекте), Google Sheets, импорт в CRM.

## Установка

**Claude Code (CLI, VS Code, JetBrains)**

```bash
# для всех проектов
git clone https://github.com/KsenNau/contacts-lpr.git ~/.claude/skills/contacts-lpr-repo
cp -r ~/.claude/skills/contacts-lpr-repo/contacts-lpr ~/.claude/skills/

# или только для одного проекта
cp -r contacts-lpr <ваш-проект>/.claude/skills/
```

Перезапустите Claude Code. Вызов: `/contacts-lpr` или фразой «собери базу контактов по …».

**claude.ai** — упакуйте папку `contacts-lpr` в zip и загрузите в Settings → Capabilities → Skills.

**Любой другой ассистент** — скормите содержимое `contacts-lpr/SKILL.md` и справочников как инструкцию.

## Структура

| Файл | Назначение |
|---|---|
| `contacts-lpr/SKILL.md` | Ядро: 5 фаз, правила, ранжирование, структура базы |
| `contacts-lpr/references/interview.md` | Банк вопросов брифа |
| `contacts-lpr/references/longlist.md` | Фаза 1: пять заходов, дедупликация, отбраковка, расширение критериев |
| `contacts-lpr/references/sources.md` | Карта источников + поисковые операторы |
| `contacts-lpr/references/output-formats.md` | Форматы выдачи, JSON-схема, правила выгрузки в CRM |
| `contacts-lpr/scripts/make_xlsx.py` | Сборка XLSX из собранного JSON (`pip install openpyxl`) |

Разделение не случайно: ядро грузится всегда, справочники — только когда дошло до соответствующего шага.

## Принципы, зашитые в скилл

- **Не выдумывать.** Нет данных — «не найдено». Выведенная по паттерну почта помечается как гипотеза.
- **Каждый факт — со ссылкой на источник.** Факт без URL в таблицу не попадает.
- **Только открытые источники.** Никаких слитых баз, «пробива», агрегаторов чужих личных контактов,
  домашних адресов, персональных данных вне бизнес-контекста.
- **Ничего не пишется в CRM** без предпросмотра «будет создано N записей» и явного подтверждения.

## Правовая рамка

Скилл работает с тем, что компания опубликовала сама, или с тем, что публично по закону
(ЕГРЮЛ, госзакупки, арбитраж). Персональные данные — в рамках 152-ФЗ, только в бизнес-контексте.

Для холодного касания рекламного характера формально требуется согласие (38-ФЗ):
персональное деловое письмо конкретному ЛПР безопаснее массовой рассылки. Ответственность
за использование собранных данных — на пользователе.

Источники ориентированы на российский рынок (ЕГРЮЛ, ФНС, zakupki.gov.ru, hh.ru, 2GIS);
логика фаз универсальна — под другой рынок меняется только `references/sources.md`.
